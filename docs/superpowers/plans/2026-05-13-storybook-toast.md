# Storybook + Toast Stories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install Storybook 8 at the workspace root (`DS-Projects/`) and create interactive stories for the existing `ToastComponent`.

**Architecture:** Storybook runs standalone using `@storybook/angular` with its own webpack build — it does NOT use Angular CLI builders. Stories live in `projects/ngx-ds/stories/`. The global SCSS (`ngx-ds/styles/index.scss`) is imported in `preview.ts`; a `postcss.config.js` bridges TailwindCSS into Storybook's webpack. Each story uses a local wrapper component (not exported to `public-api.ts`) that injects `ToastrService` and renders buttons to trigger toasts.

**Tech Stack:** Storybook 8, `@storybook/angular`, `@storybook/addon-essentials`, TailwindCSS v3, Angular 21 standalone components.

### Task 1: Install Storybook

**Files:**
- Create: `.storybook/main.ts` (auto-generated by init)
- Create: `.storybook/preview.ts` (auto-generated by init)
- Modify: `package.json` (scripts added by init, packages added to devDependencies)

Context: Our workspace has no default Angular application — only the `ngx-ds` library. The `--type angular` flag forces Storybook to detect Angular from `package.json` dependencies without needing an app project.

- [ ] **Step 1: Run Storybook init**

From `DS-Projects/` (workspace root):

```bash
npx storybook@latest init --type angular --yes
```

Expected output: Storybook installs packages, generates `.storybook/main.ts` and `.storybook/preview.ts`, and adds scripts to `package.json`. This may take 2–3 minutes.

If the command fails with a peer dependency error, re-run with:

```bash
npx storybook@latest init --type angular --yes -- --legacy-peer-deps
```

- [ ] **Step 2: Verify devDependencies**

Open `package.json`. Confirm these packages appear in `devDependencies` (exact minor versions may differ):

```json
"@storybook/addon-essentials": "^8.x.x",
"@storybook/addon-interactions": "^8.x.x",
"@storybook/angular": "^8.x.x",
"storybook": "^8.x.x"
```

If any are missing, install them:

```bash
npm install --save-dev storybook @storybook/angular @storybook/addon-essentials @storybook/addon-interactions
```

- [ ] **Step 3: Verify npm scripts**

`package.json` `scripts` block must include:

```json
"storybook": "storybook dev -p 6006",
"build-storybook": "storybook build"
```

If missing (init sometimes skips this), add them manually next to the existing scripts in `package.json`.

- [ ] **Step 4: Delete auto-generated sample stories**

Storybook init creates a `src/stories/` directory with example files. Delete it:

```bash
# PowerShell
Remove-Item -Recurse -Force src/stories -ErrorAction SilentlyContinue
```

- [ ] **Step 5: Commit**

```bash

git commit -m "chore: install Storybook 8 for ngx-ds"
```

**Files:**

### Task 3: Configure preview.ts and PostCSS

**Files:**
- Modify: `.storybook/preview.ts`
- Create: `postcss.config.js`

`@storybook/angular` uses webpack internally. For `@tailwind base/components/utilities` in `styles/index.scss` to compile, webpack needs a PostCSS config with the Tailwind plugin. This `postcss.config.js` is for Storybook only — Angular CLI's `@angular/build:application` (esbuild) auto-detects Tailwind from `tailwind.config.js` without it.

- [ ] **Step 1: Replace `.storybook/preview.ts`**

```ts
import type { Preview } from '@storybook/angular';
import '../projects/ngx-ds/styles/index.scss';

const preview: Preview = {
  parameters: {
    controls: {
      matchers: {
        color: /(background|color)$/i,
        date: /Date$/,
      },
    },
  },
};

export default preview;
```

- [ ] **Step 2: Create `postcss.config.js` at workspace root**

```js
// Required by Storybook's webpack build to compile @tailwind directives.
// Angular CLI (@angular/build:application esbuild) does NOT use this file.
module.exports = {
  plugins: {
    tailwindcss: {},
    autoprefixer: {},
  },
};
```

- [ ] **Step 3: Verify global styles load**

```bash
npm run storybook
```

Expected: Storybook opens at `http://localhost:6006`. No CSS or SCSS compilation errors in the terminal. (Visual effect of the global stylesheet is invisible without stories — check the terminal output, not the browser.)

Stop with **Ctrl+C**.

- [ ] **Step 4: Commit**

```bash
git add .storybook/preview.ts postcss.config.js
git commit -m "chore: configure Storybook preview with TailwindCSS global styles"
```

### Task 4: Create Toast Stories

**Files:**
- Create: `projects/ngx-ds/stories/toast/toast.stories.ts`

**Context about the existing code:**

- `ToastComponent` (`projects/ngx-ds/src/lib/components/toast/toast.component.ts`):
  - Selector: `app-toast`
  - Standalone, imports `CommonModule`
  - Injects `ToastrService` directly — has no `@Input` props
  - Groups toasts by position using a computed signal

- `ToastrService` (`projects/ngx-ds/src/lib/services/toast.service.ts`):
  - `providedIn: 'root'`, signal-based
  - `success(message, title?, duration?)` → fires success toast at `top-right` by default
  - `error(message, title?, duration?)`
  - `warning(message, title?, duration?)`
  - `info(message, title?, duration?)`
  - `show({ message, type?, duration?, position?, title? })` → full control including position
  - `remove(id)`, `clear()`

- `ToastPosition`: `'top-right' | 'top-left' | 'bottom-right' | 'bottom-left'`

The stories use relative imports (not the `ngx-ds` alias) to avoid any TypeScript path resolution differences between Angular CLI and Storybook's webpack.

- [ ] **Step 1: Create the stories directory**

```bash
New-Item -ItemType Directory -Force projects/ngx-ds/stories/toast
```

- [ ] **Step 2: Create `projects/ngx-ds/stories/toast/toast.stories.ts`**

```ts
import { applicationConfig, Meta, StoryObj } from '@storybook/angular';
import { Component, inject } from '@angular/core';
import { provideAnimations } from '@angular/platform-browser/animations';
import { ToastComponent } from '../../src/lib/components/toast/toast.component';
import { ToastrService, ToastPosition } from '../../src/lib/services/toast.service';

// ─── Default Story Wrapper ───────────────────────────────────────────────────

@Component({
  selector: 'toast-default-wrapper',
  standalone: true,
  imports: [ToastComponent],
  template: `
    <div class="p-6 space-y-4">
      <p class="text-sm text-gray-500 mb-2">
        Haz clic en los botones para disparar toasts.
      </p>
      <div class="flex flex-wrap gap-2">
        <button
          (click)="showSuccess()"
          class="px-4 py-2 bg-green-500 text-white rounded hover:bg-green-600 transition-colors"
        >
          Success
        </button>
        <button
          (click)="showError()"
          class="px-4 py-2 bg-red-500 text-white rounded hover:bg-red-600 transition-colors"
        >
          Error
        </button>
        <button
          (click)="showWarning()"
          class="px-4 py-2 bg-yellow-500 text-white rounded hover:bg-yellow-600 transition-colors"
        >
          Warning
        </button>
        <button
          (click)="showInfo()"
          class="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600 transition-colors"
        >
          Info
        </button>
      </div>
      <app-toast />
    </div>
  `,
})
class DefaultWrapper {
  private toastrService = inject(ToastrService);

  showSuccess(): void {
    this.toastrService.success('Operación completada con éxito', 'Éxito');
  }

  showError(): void {
    this.toastrService.error('Ha ocurrido un error inesperado', 'Error');
  }

  showWarning(): void {
    this.toastrService.warning('Verifica los datos antes de continuar', 'Advertencia');
  }

  showInfo(): void {
    this.toastrService.info('Nueva actualización disponible', 'Información');
  }
}

// ─── All Types Wrapper ────────────────────────────────────────────────────────

@Component({
  selector: 'toast-all-types-wrapper',
  standalone: true,
  imports: [ToastComponent],
  template: `
    <div class="p-6 space-y-4">
      <p class="text-sm text-gray-500 mb-2">
        Dispara los cuatro tipos de toast simultáneamente.
      </p>
      <button
        (click)="showAll()"
        class="px-4 py-2 bg-gray-800 text-white rounded hover:bg-gray-900 transition-colors"
      >
        Mostrar todos los tipos
      </button>
      <app-toast />
    </div>
  `,
})
class AllTypesWrapper {
  private toastrService = inject(ToastrService);

  showAll(): void {
    this.toastrService.success('Archivo guardado correctamente', 'Éxito', 8000);
    this.toastrService.error('No se pudo conectar al servidor', 'Error', 8000);
    this.toastrService.warning('El formulario tiene campos vacíos', 'Advertencia', 8000);
    this.toastrService.info('Hay una nueva versión disponible', 'Información', 8000);
  }
}

// ─── All Positions Wrapper ────────────────────────────────────────────────────

@Component({
  selector: 'toast-positions-wrapper',
  standalone: true,
  imports: [ToastComponent],
  template: `
    <div class="p-6 space-y-4">
      <p class="text-sm text-gray-500 mb-2">
        Haz clic en cada botón para ver el toast en esa posición.
      </p>
      <div class="grid grid-cols-2 gap-2 max-w-xs">
        <button
          (click)="show('top-left')"
          class="px-3 py-2 bg-indigo-500 text-white text-sm rounded hover:bg-indigo-600 transition-colors"
        >
          Top Left
        </button>
        <button
          (click)="show('top-right')"
          class="px-3 py-2 bg-indigo-500 text-white text-sm rounded hover:bg-indigo-600 transition-colors"
        >
          Top Right
        </button>
        <button
          (click)="show('bottom-left')"
          class="px-3 py-2 bg-indigo-500 text-white text-sm rounded hover:bg-indigo-600 transition-colors"
        >
          Bottom Left
        </button>
        <button
          (click)="show('bottom-right')"
          class="px-3 py-2 bg-indigo-500 text-white text-sm rounded hover:bg-indigo-600 transition-colors"
        >
          Bottom Right
        </button>
      </div>
      <app-toast />
    </div>
  `,
})
class AllPositionsWrapper {
  private toastrService = inject(ToastrService);

  show(position: ToastPosition): void {
    this.toastrService.show({
      message: `Toast apareciendo en ${position}`,
      type: 'info',
      position,
      title: `Posición: ${position}`,
    });
  }
}

// ─── Meta ─────────────────────────────────────────────────────────────────────

const meta: Meta = {
  title: 'Components/Toast',
  decorators: [
    applicationConfig({
      providers: [provideAnimations()],
    }),
  ],
};

export default meta;
type Story = StoryObj;

// ─── Stories ──────────────────────────────────────────────────────────────────

export const Default: Story = {
  render: () => ({
    component: DefaultWrapper,
  }),
};

export const AllTypes: Story = {
  render: () => ({
    component: AllTypesWrapper,
  }),
};

export const AllPositions: Story = {
  render: () => ({
    component: AllPositionsWrapper,
  }),
};
```
