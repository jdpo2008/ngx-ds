# UserMenu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `UserMenuComponent` organism that shows an avatar trigger button and a dropdown panel with user info (name + email) and a configurable list of actions.

**Architecture:** The component wraps the existing `PopoverComponent` for all open/close/click-outside/escape behavior. The trigger slot receives a `<button>` containing `AvatarComponent`. The content slot receives a panel with a name+email header, a divider, and a list of `MenuButtonComponent` instances driven by an `actions` input array.

**Tech Stack:** Angular 21 standalone components, signal-based API (`input()`, `output()`), `ChangeDetectionStrategy.OnPush`, lucide-angular icons, SCSS with CSS custom properties.

```typescript
import {
  ChangeDetectionStrategy,
  Component,
  input,
  output,
} from '@angular/core';
import { AvatarComponent } from '../../atoms/avatar/avatar.component';
import { MenuButtonComponent } from '../../atoms/menu-button/menu-button.component';
import { DividerComponent } from '../../atoms/divider/divider.component';
import { PopoverComponent } from '../popover/popover.component';
import type { PopoverPlacement } from '../popover/popover.component';
import type { UserMenuUser, UserMenuAction, AvatarSize } from './user-menu.types';

export type { UserMenuUser, UserMenuAction };

@Component({
  selector: 'ngx-ds-user-menu',
  standalone: true,
  imports: [PopoverComponent, AvatarComponent, MenuButtonComponent, DividerComponent],
  templateUrl: './user-menu.component.html',
  styleUrl: './user-menu.component.scss',
  changeDetection: ChangeDetectionStrategy.OnPush,
})
export class UserMenuComponent {
  readonly user      = input.required<UserMenuUser>();
  readonly actions   = input<UserMenuAction[]>([]);
  readonly placement = input<PopoverPlacement>('bottom-end');
  readonly size      = input<AvatarSize>('md');

  readonly actionClick = output<UserMenuAction>();

  onAction(action: UserMenuAction): void {
    if (action.disabled) return;
    this.actionClick.emit(action);
  }
}
```

## Task 3: Template

**Files:**
- Create: `projects/ngx-ds/src/lib/organisms/user-menu/user-menu.component.html`

- [ ] **Step 1: Create the template**

```html
<ngx-ds-popover [placement]="placement()">

  <!-- ── Trigger ─────────────────────────────────────────────────────────── -->
  <button
    popover-trigger
    type="button"
    class="um__trigger"
    [attr.aria-label]="user().name"
  >
    <ngx-ds-avatar
      [src]="user().avatarSrc"
      [initials]="user().initials ?? ''"
      [color]="user().avatarColor ?? 'primary'"
      [size]="size()"
    />
  </button>

  <!-- ── Panel ───────────────────────────────────────────────────────────── -->
  <div popover-content class="um__panel">

    <!-- Header: name + email only, no avatar -->
    <div class="um__header">
      <p class="um__name">{{ user().name }}</p>
      <p class="um__email">{{ user().email }}</p>
    </div>

    <ngx-ds-divider />

    <!-- Action list -->
    <div class="um__actions">
      @for (action of actions(); track action.id) {
        @if (action.separator) {
          <ngx-ds-divider />
        }
        <ngx-ds-menu-button
          [iconLeft]="action.icon"
          [color]="action.color ?? 'default'"
          [disabled]="action.disabled ?? false"
          [fullWidth]="true"
          (click)="onAction(action)"
        >
          {{ action.label }}
        </ngx-ds-menu-button>
      }
    </div>

  </div>

</ngx-ds-popover>
```
